# Ferretería El Tornillo

Sitio web estático *one-page* moderno y responsivo para el negocio de barrio **Ferretería El Tornillo**, ubicado en Calle 10 #23-45, barrio Los Pinos.

## 🛠️ Estructura del Proyecto

```text
ferreteria-el-tornillo/
├── index.html          # Estructura principal semántica (Inicio, Productos/Servicios, Contacto)
├── css/
│   └── estilos.css     # Estilos responsivos, diseño industrial moderno y animaciones
└── js/
    └── contacto.js     # Validaciones del formulario (nombre >= 2 caracteres) y menú móvil
```

## 📋 Características

- **Sección 1: Inicio**: Nombre comercial, eslogan, horarios de atención (Lunes a sábado, 8:00 a.m. a 6:00 p.m.) y dirección.
- **Sección 2: Productos y Servicios**: 4 tarjetas destacadas (*Herramientas*, *Pintura y Accesorios*, *Tornillería y Fijaciones*, *Material Eléctrico*).
- **Sección 3: Contacto**: Panel con información de contacto y formulario con validación en cliente.
- **Tecnologías**: HTML5, CSS3 y JavaScript nativo (sin frameworks ni dependencias).
- **Responsive**: Optimizado para pantallas de escritorio, tablets y dispositivos móviles.
